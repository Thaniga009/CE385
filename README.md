4.2
เป็นการทำงานแบบ asynchronous โดยเปรียบเทียบการใช้callback,promise ผ่านการจำลองการดึงข้อมูล
ที่ใช้เวลา 2 วินาที เมื่อได้ข้อมูลแล้วโปรแกรมจะแสดงผลลัพธ์ออกทางหน้าจอเพื่อให้เห็นความแตกต่างของการรับค่าผลลัพธ์ของ2ตัว
4.3
การทำงานแบบ asynchronous โดยใช้ Promiseกับasync/await ฟังก์ชันจะจำลองงานที่ต้องรอเวลา 
ถ้าเวลาที่ส่งเข้ามาน้อยกว่า 1000 มิลลิวินาทีก็จะ error แต่ถ้ามากกว่านั้นก็จะทำงานสำเร็จ ผลลัพธ์ที่ได้หรือเออเร่่อจะถูกจัดการด้วย
try/catch และแสดงผลลัพธ์
4.4
โค้ดนี้ทำงานกับ Promise หลายตัวพร้อมกัน โดยใช้ Promise.any เพื่อเอาผลลัพธ์ที่ได้ตัวแรกมาใช้ แม้ว่าบางเซิร์ฟเวอร์จะerrorก็ตามแล้วก็ใช้Promise.allSettled 
เพื่อดูผลลัพธ์ของทุกเซิร์ฟเวอร์ว่าตัวไหนสำเร็จหรือล้มเหลวโดยไม่หยุดการทำงานเมื่อเกิด errorเหมาะกับการเช็กสถานะของทุกคำขอพร้อมกัน
