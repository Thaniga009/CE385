เป็นระบบ backend ที่เชื่อม AI (LLM) เข้ากับฐานข้อมูลผ่าน MCP (Model Context Protocol) โดยใช้ Prisma จัดการ database และมี tool สำหรับให้ AI เรียกใช้งานในการ query ข้อมูลแทนการเข้าถึง DB โดยตรง พร้อมทั้งมี API รองรับทั้งการเรียก tool และการ chat กับ AI ทำให้สามารถสร้างระบบที่ให้ AI ตอบคำถามจากข้อมูลจริงใน database ได้แบบปลอดภัยและควบคุมได้
